FOTNEWS
A simple Android application for displaying news and updates, seemingly for the Faculty of Technology (FOT).

📖 About This Project
This project is an Android application built with Java. Based on the name "FOTNEWS," its purpose is to serve as a news and information hub for students and staff of the Faculty of Technology. It likely fetches and displays articles, notices, and updates relevant to the faculty.

🛠️ Technologies Used
Language: Java

Framework: Android SDK

Build Tool: Gradle

🚀 Getting Started
To get a local copy up and running, follow these simple steps.

Prerequisites
You will need the following software installed on your machine:

Android Studio (latest stable version recommended)

Java Development Kit (JDK) (usually bundled with Android Studio)

Installation & Setup
Clone the repository:

Bash

git clone https://github.com/Sehan1109/FOTNEWS.git
Open in Android Studio:

Open Android Studio.

Select "Open an Existing Project".

Navigate to the cloned FOTNEWS directory and select it.

Sync Gradle:

Android Studio will automatically detect the build.gradle.kts file and sync the project's dependencies. This may take a few minutes.

Run the Application:

Once the Gradle sync is complete, you can run the app.

Select an emulator (AVD) or connect a physical Android device.

Click the "Run 'app'" button (green play icon) in the toolbar.
